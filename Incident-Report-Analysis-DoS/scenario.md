You are a cybersecurity analyst working for a multimedia company that provides web design, graphic design, and social media marketing solutions to small businesses. Your organization recently experienced a DoS attack that compromised the internal network for two hours until the issue was resolved.
During the attack, your organization's network services suddenly stopped responding due to a flood of incoming ICMP packets. Normal internal network traffic could not access any network resources. The incident management team responded by blocking incoming ICMP packets, taking all non-critical network services offline, and restoring critical network services.
The company's cybersecurity team then investigated the security incident. They discovered that a malicious actor had sent a flood of ICMP pings to the company's network through a misconfigured firewall. This vulnerability allowed the malicious attacker to overwhelm the company's network with a Denial-of-Service (DoS) attack.
To address this security issue, the network security team implemented the following measures:
- A new firewall rule to limit the rate of incoming ICMP packets.
- Source IP address verification on the firewall to check for spoofed IP addresses in incoming ICMP packets.
- Network monitoring software to detect anomalous traffic patterns.
- An IDS/IPS system to filter some ICMP traffic based on suspicious characteristics.
As a cybersecurity analyst, you have been tasked with using this security event to create a plan to improve your company's network security, following the National Institute of Standards and Technology (NIST) Cybersecurity Framework (CSF). You will use the CSF to help you navigate the different steps of analyzing this cybersecurity event and integrate your analysis into an overall security strategy. We have divided the analysis into different sections in the template below. You can explore them here:
- Identify: Identify security risks through regular audits of internal networks, systems, devices, and access privileges to identify potential security gaps.
- Protect: Protect internal assets by implementing policies, procedures, training, and tools that help mitigate cybersecurity threats.
- Detect: Detect potential security incidents and improve monitoring capabilities to increase the speed and effectiveness of detection.
- Respond: Respond to contain, neutralize, and analyze security incidents, and implement improvements to the security process.
- Recover: Restore the normal operation of affected systems and restore data and/or system assets that have been affected by an incident.
